# Portfolio - Abdou Anfani

Site statique prêt à être déployé. Structure :

- index.html
- src/styles.css
- src/main.js
- data/*.json  (experiences, projects, skills)
- assets/*.svg

Pour lancer en local (dans le dossier portfolio) :

Python 3:  python -m http.server 8000
Ou utilisez une extension Live Server dans votre éditeur.

Modifier les données : éditez les fichiers JSON dans data/.
Modifier les couleurs : ajustez les variables CSS dans src/styles.css (section :root).

Respectez la règle : ne pas inventer d'informations — remplacez les placeholders [À compléter] par vos données réelles.
